## 当前演示

离线演示：

~~~powershell
minicode run --provider fake "调用 echo 工具"
~~~

真实中转站对话：

~~~powershell
$env:MINICODE_API_KEY = "你的 Key"
minicode run --provider relay --model gpt6.1sol --reasoning-effort high "你好，请介绍自己"
~~~
